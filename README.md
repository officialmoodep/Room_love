# اتاق ما — نسخه‌ی بدون Firebase

سایت دیگه به هیچ سرویس گوگل (Firebase) وابسته نیست. یک سرور Node.js کوچک (`server.js`) هم صفحه‌ها رو سرو می‌کنه
و هم چت، اتاق‌ها، هماهنگی ویدیو و سیگنال تماس رو از طریق WebSocket (`/ws`) رد و بدل می‌کنه.

## اجرا
    npm install
    npm start          # پورت از متغیر PORT (پیش‌فرض 3000)

سایت رو از همون آدرس سرور باز کن. چون تماس تصویری به HTTPS نیاز داره، حتماً پشت HTTPS منتشرش کن.

## جای دیپلوی
هر هاستی که Node.js و WebSocket رو پشتیبانی کنه و داخل ایران بدون فیلترشکن باز بشه (پلتفرم‌های ابری ایرانی یا یک VPS).
Vercel وب‌سوکت نگه نمی‌داره؛ سرور باید جای دیگه‌ای اجرا بشه. اگه صفحه رو جای دیگه نگه می‌داری،
در index.html مقدار WS_URL رو بذار مثلاً wss://your-app.example.ir/ws

## متغیرهای محیطی (اختیاری)
- DATA_FILE : مسیر فایل ذخیره‌ی اتاق‌ها و پیام‌ها (پیش‌فرض ./data/db.json). روی هاست ابری یه دیسک دائمی بهش وصل کن؛ وگرنه با هر ری‌استارت پاک می‌شه.
- ICE_SERVERS : سرورهای STUN/TURN تماس (JSON). مثال:
  [{"urls":"stun:stun.example.com:3478"},{"urls":"turn:turn.example.com:3478","username":"u","credential":"p"}]
  اگه خالی باشه از STUN گوگل و TURN عمومی استفاده می‌شه که تو ایران ممکنه بسته باشه. برای تماس مطمئن، روی یک VPS سرور coturn راه بنداز و آدرسش رو اینجا بذار.

## دو دیتابیس: اصلی و یدک
در index.html آرایه‌ی BACKENDS = ["ws", "firebase"] تعیین می‌کنه کدوم اصلیه (اولی) و کدوم یدک (دومی).
- ساخت اتاق: اول روی سرور خودت؛ اگه وصل نشد روی Firebase ساخته می‌شه.
- ورود با کد: هر دو هم‌زمان جستجو می‌شن و به همونی که اتاق توشه وصل می‌شی.
- هر اتاق فقط تو یکی از دو دیتابیس هست و بینشون همگام‌سازی نمی‌شه؛ پس هر دو نفر باید بتونن به دیتابیسی که اتاق توشه برسن
  (مثلاً اتاق Firebase برای کسی که Firebase براش فیلتره باز نمی‌شه).
- برای استفاده از Firebase، فایل database.rules.json رو تو Firebase Console منتشر کن.

## یوتیوب
لینک یوتیوب با YouTube IFrame API (رایگان، بدون کلید) پخش و بین دو نفر هماهنگ می‌شه (پخش، توقف، جلو/عقب، سرعت).
اسکریپت پلیر از youtube.com لود می‌شه، پس تو ایران روی هر دو گوشی فیلترشکن لازمه.

## پخش زنده‌ی فیلم (📡)
یک نفر «📡 پخش زنده برای پارتنر» رو می‌زنه و فایل رو از گوشی خودش انتخاب می‌کنه؛ تصویر مستقیم برای پارتنر پخش می‌شه (بدون آپلود). کیفیت با دکمه‌ی کنار CC عوض می‌شه: A (خودکار)، 720، 480، 360، 240؛ هر دو نفر می‌تونن عوضش کنن. مرورگر فرستنده باید captureStream داشته باشه (Chrome اندروید/کامپیوتر) و گوشی فرستنده آنلاین بمونه.
